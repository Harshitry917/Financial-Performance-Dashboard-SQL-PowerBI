📊 Financial Performance & Profitability Dashboard
🚀 Project Overview

This project is a Financial Data Analysis Dashboard built using SQL and Power BI.
It helps in analyzing a company's financial performance by tracking revenue, expenses, profit, department performance, and salary efficiency.

The main goal is to convert raw financial data into meaningful business insights for better decision-making.

🛠️ Tools & Technologies Used
SQL (Data Extraction & Analysis)
Power BI (Dashboard & Visualization)
Excel (Data Preparation)
Data Modeling & Relationships
📁 Dataset Structure

The project includes the following tables:

Financial Data (Revenue, Expense, Date, Dept ID)
Department Table (Department Details)
Employee Data (Salary Information)

📊 Key Features & Analysis

💰 1. Overall Financial Performance
Total Revenue
Total Expense
Total Profit

📅 2. Monthly Trend Analysis
Revenue vs Expense trends over time
Profit fluctuation analysis

🏢 3. Department-wise Performance
Revenue by department
Profit contribution per department
Performance comparison

💸 4. Budget vs Actual Analysis
Planned vs actual expense comparison
Overspending detection

👨‍💼 5. Salary Analysis
Total salary cost per department
Workforce cost distribution

⚖️ 6. Salary vs Revenue Efficiency
Cost efficiency analysis
Revenue vs salary comparison

📊 Dashboard Visuals

KPI Cards (Revenue, Expense, Profit, Profit Margin)
Line Chart (Monthly Trends)
Bar Charts (Department Performance)
Scatter Plot (Efficiency Analysis)
Interactive Filters (Year, Department)

📈 Key Insights

Identified top-performing departments
Found cost-heavy areas in the business
Analyzed profit trends over time
Measured employee cost efficiency
